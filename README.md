# IAqui

Site institucional da IAqui: inteligência artificial sob medida para pequenas e médias empresas e MEIs. Planos mensais sem fidelidade.

Site estático (HTML, CSS e JavaScript puro), publicado pelo GitHub Pages a partir da branch `main`.

- `index.html`: conteúdo da página
- `style.css`: visual (paleta e tipografia do manual da marca)
- `script.js`: WhatsApp, e-mail e formulário de contato
- `assets/`: logo, favicon e imagem de compartilhamento
- `demo/`: demonstração de atendente com IA no estilo WhatsApp (roda só no navegador, sem API). Link por ramo: `demo/?ramo=clinica`, `academia` ou `pet`
